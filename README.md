# Amazon India E-Commerce Sales & Operations Analytics

## Project Overview
An end-to-end exploratory data analysis project using an Amazon India seller/order report dataset. The project examines sales patterns, product performance, order cancellations, fulfilment methods, shipping service levels, and regional demand.

## Tools & Technologies
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Plotly
- Jupyter Notebook / Kaggle
- Excel

## Dataset
- 128,969 product records
- 120,378 unique orders
- Reporting period: March–June 2022

## Key Analysis
- Monthly order and recorded amount trends
- Product category and SKU performance
- Order cancellation analysis
- Fulfilment and shipping comparisons
- State and city-level analysis
- Order value and high-value record analysis
- B2B vs B2C comparison
- Promotion ID analysis

## Key Findings
- Overall order cancellation rate: 14.28%
- Average eligible recorded order value: ₹711.44
- Set category contributed 49.88% of recorded amount.
- Maharashtra had the highest recorded amount.
- Standard shipping cancellation rate: 17.16%, compared with 12.97% for Expedited.

## Deliverables
- Complete Jupyter Notebook with Python analysis and interactive visualizations.
- Excel workbook containing multiple analysis sheets.

## Methodology & Limitations
Data cleaning, duplicate removal, missing-value assessment, exploratory analysis, KPI development, and visualization were performed.

Recorded amount should not be interpreted as verified realized revenue or profit. The dataset represents seller/order report data, not Amazon's internal company-wide sales data. March and June are partial months.
